About

Tallimedia is a private site for app development. I wanted to start using Claude Code to develop apps for my own use, and wanted to share them for anyone likeminded.

Everything published here is a personal project, run on a best-effort basis with no service-level agreement. Sources are open where the licence allows it.

How it's built
Monkey C on the watch, a small FastAPI backend, and Claude Code doing most of the typing.

No analytics, no third-party trackers on any app published here.
